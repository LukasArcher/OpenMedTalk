# Contributing
Read AGENTS.md and the product, design, architecture and clinical docs. Use small pull requests, clear conventional code, tests and a concise description of behavior changes. Do not include real patient information or screenshots. Clinical items must be independently reviewed, versioned and released through the specified gate. Do not submit generated translations as verified. AI-assisted code or text must meet the same review requirements as human contributions. For translation work, use the future editorial portal; until available, only synthetic or clearly draft material should be submitted. By contributing, you agree to the repository license applicable to the material; confirm future split licenses before accepting contributions under them.
