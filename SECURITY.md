# Security and clinical content reports
Never include patient names, identifiers, anamnesis, logs, QR payloads or real patient screenshots in GitHub issues, discussions, pull requests or translation submissions. Report software vulnerabilities privately using GitHub private vulnerability reporting when enabled; otherwise contact the maintainer privately without patient data. Clinical translation concerns should include locale, item ID, source/translation revision, problematic text and suggested correction, not patient details. Severe clinical concerns require immediate maintainer triage and possible withdrawal. Offline installations cannot be remotely revoked; communicate affected versions and update guidance. No public clinical release has yet been approved.
